AI Student Assistant

An AI-powered study tool built at CatHacks and significantly expanded after the hackathon. Paste text or upload a PDF to get instant explanations, summaries, and key concept breakdowns — then ask follow-up questions in context.

Live Demo View Code

// Inspiration

Built to make studying faster and smarter.

Started at CatHacks with a simple idea: let students paste any text and get an instant explanation. After the hackathon, I kept building — adding PDF upload, contextual follow-up chat, persistent session history, and a fully rebuilt interface. The goal is to make dense academic material immediately approachable.

AI Learning

Conversational AI powered by OpenAI's GPT-4o mini, with tailored prompts per action for structured, useful output.

PDF Analysis

Client-side PDF parsing via PDF.js — no file upload to a server. Works entirely in the browser.

// Features

What the assistant can do.

Explain

Breaks down any concept or passage into plain language, with analogies and step-by-step reasoning.

Summarize

Extracts the main idea and key points from long documents or notes into a concise summary.

Key Concepts

Identifies and defines the most important terms in any passage, ordered from fundamental to complex.

PDF Upload

Drag and drop any PDF. Text is extracted client-side using PDF.js and analyzed instantly.

Follow-up Chat

Ask questions about any result. The assistant remembers the full context of the session.

Session History

All sessions are saved locally and accessible from the sidebar — no account required.

// Technologies

The stack behind the project.

Frontend

Vanilla JavaScript, HTML, CSS — no framework

OpenAI API

GPT-4o mini with action-specific system prompts

PDF.js

Client-side PDF text extraction, no backend required

localStorage

Persistent session history stored in the browser
