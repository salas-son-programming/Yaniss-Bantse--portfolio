FULL STACK PROJECT

SocialBook

A Social Media Platform Built With Django

SocialBook is a full-stack social media application inspired by Facebook. Users can create accounts, customize profiles, upload images, create posts, interact with content, and connect with other users.

Try SocialBook GitHub Repository

Features

User Authentication

Secure registration, login, and logout system.

Create Posts

Users can publish content and share updates.

Image Uploads

Upload profile pictures and post images.

User Profiles

Personalized profiles with account information.

Database Integration

Data stored and managed through Django ORM.

AWS Deployment

Deployed on AWS Elastic Beanstalk.

Technologies Used

Python Django HTML CSS JavaScript SQLite AWS
